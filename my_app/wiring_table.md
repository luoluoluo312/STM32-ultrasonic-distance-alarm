# 项目一：光照监测与天黑报警器 —— 接线表与调试指南

## 1. 本项目用到的元器件

| 元器件 | 作用 |
| --- | --- |
| STM32F103C8T6 蓝板 | 主控 |
| ST-Link V2 | 下载程序 + 供电 + 调试 |
| 0.96 寸 I2C OLED | 显示四页界面 |
| 光敏传感器模块 | PA0 采集环境光（AO 模拟输出） |
| 电位器模块 | PA1 采集旋钮位置（当"灵敏度/参考值"用） |
| 无源蜂鸣器模块 | PB6 用 PWM 发声（报警 + 按键提示音） |
| 4 个按键 | 翻页 / 加 / 减 / 报警开关 |
| USB 转 TTL (CH340) | 电脑上看数据（115200 8N1） |
| 面包板 + 杜邦线 | 搭电路 |

> **不需要 W25Q64 Flash 模块**（v1.1 已把它去掉）：历史统计改成存在单片机的内存里，
> 代价是掉电后统计和阈值设置会回到默认值。Flash 模块留在盒子里就行。

## 2. 总原则（三条，务必先看）

1. **所有模块的 GND 必须和蓝板的 GND 连在一起**（共地），否则读数乱跳。
2. **模块供电全部用蓝板的 3V3**。光敏模块如果用 5V 供电，AO 会输出接近 5V 的电压，
   超过 STM32 的 ADC 上限（3.3V），会把引脚打坏。
3. 蓝板总电流有限（3.3V 引脚大概只能再带 100~150mA），本项目所有模块都很省电，没问题；
   但不要用 5V 去驱动电机（那是下一个项目的事）。

## 3. 逐模块接线表

### 3.1 OLED（4 针：GND VCC SCL SDA）

| OLED 引脚 | 接到蓝板 | 说明 |
| --- | --- | --- |
| GND | GND | |
| VCC | 3V3 | 不要接 5V |
| SCL | **PB8** | 和你原来的笑脸程序一致 |
| SDA | **PB9** | 和你原来的笑脸程序一致 |

> 这两个脚是"软件 I2C"，程序里用 `SI2C` 驱动，所以**不要**去接 5V 或者接 A4/A5。

### 3.2 光敏传感器模块（LM393 型，4 针）

你的模块正面丝印从左到右是 **AO DO GND VCC**（板上有一颗 LM393 比较器和一颗蓝色小电位器）：

| 模块引脚 | 接到蓝板 | 说明 |
| --- | --- | --- |
| AO | **PA0** | 模拟输出，接 ADC 测环境亮度 |
| DO | 不接 | 比较器数字输出（阈值由板上蓝色小电位器调），本项目用不到 |
| GND | GND | |
| VCC | 3V3 | **必须 3.3V**，接 5V 会把 PA0 打坏 |

> 模块上那颗蓝色小电位器只管 DO 的翻转阈值，对我们的 AO 采样没有任何影响，
> 想让 DO 的指示灯在某个亮度下亮，转它就行（属于附加玩法）。
>
> **方向（重要）**：你这个模块的特点是"**光越强，AO 电压越低**"，
> 程序里已经按这个特性校准好了（`main.c` 里的 `LIGHT_BIG_IS_BRIGHT = 0`），
> 所以界面上"光照"数字**越大 = 环境越亮，越小 = 环境越暗**，
> 报警逻辑是"**光照低于阈值就报警（天黑报警）**"。

### 3.3 电位器（B10K 三脚可调电阻，裸元件）

套件里这个是**没有小板子的裸电位器**（丝印 B10K），三个脚里**中间那个是滑动端**：

| 引脚 | 接到蓝板 | 说明 |
| --- | --- | --- |
| 中间脚 | **PA1** | 滑动端，输出电压 0~3.3V |
| 一个边脚 | 3V3 | |
| 另一个边脚 | GND | |

> 两个边脚互换不会坏，只是旋钮的增减方向相反。
> 脚比较细，插面包板时稍微用力，别把脚掰弯。

### 3.4 无源蜂鸣器模块（3 针，**低电平触发**）

你的模块正面丝印从左到右是 **VCC I/O GND**，背面印着 *Buzzer module / Low level trigger*，
所以它是"**给低电平才响**"的，程序里已经按这个特性写好了（用 PWM 模式2 输出反相方波）。

| 模块引脚 | 接到蓝板 | 说明 |
| --- | --- | --- |
| VCC | 3V3 | |
| I/O | **PB6** | 程序在这里输出方波（TIM4_CH1） |
| GND | GND | |

> 代码里有个开关 `BUZZER_ACTIVE_LOW`（1=低电平触发）。如果哪天换成了"高电平触发"的模块，
> 把它改成 0 就行，其它都不用动。

### 3.5 四个按键

每个按键只用**两个脚**：一端接下面的引脚，另一端统一接 **GND**。

| 按键 | 接到蓝板 | 功能 |
| --- | --- | --- |
| K1 | **PB12** | 单击=下一页，连击两次=上一页，长按=静音 30 秒 |
| K2 | **PB13** | 设置页里：单击 +100，长按连续微调 |
| K3 | **PB14** | 设置页里：单击 -100；历史页里长按=清空记录 |
| K4 | **PB15** | 单击=报警开关；在设置页里长按=阈值恢复默认值 |

> 程序里开了内部上拉，所以**不需要外接电阻**。
> 面包板上的四脚轻触键：同一侧的两个脚是导通的，把**对角的两个脚**分别接到引脚和 GND 最稳妥。

### 3.6 W25Q64 Flash 模块：**本项目不用**

（已从程序里去掉，接不接都不影响。盒子里的 W25Q64 先收着，以后想玩"掉电保存数据"时再接。）

### 3.7 USB 转 TTL (CH340，6 针带跳线帽)

你的模块丝印依次是 **GND RXD TXD 3V3 VCC 5V**，黄色的跳线帽是选 VCC 输出 3.3V 还是 5V 的，
**本方案根本不用它的电源**，跳线帽保持原样就行：

| CH340 引脚 | 接到蓝板 | 说明 |
| --- | --- | --- |
| GND | GND | 必须接，不接会收到乱码 |
| RXD | **PA9**（蓝板的 TX） | 交叉接 |
| TXD | **PA10**（蓝板的 RX） | 交叉接 |
| 3V3 / VCC / 5V | 不接 | 蓝板已经由 ST-Link 供电，两个电源同时接会打架 |

### 3.8 ST-Link V2（下载器）

| ST-Link | 接到蓝板 |
| --- | --- |
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V | 3V3（用 ST-Link 给蓝板供电） |

### 3.9 板载 LED

不用接线。蓝板上丝印 `PC13` 旁边的小灯：正常时 2 秒闪一下，报警时快速闪烁。

### 3.10 面包板供电轨

把蓝板的 `3V3` 和 `GND` 各引一根线到面包板两侧的电源轨。

> MB-102 这类面包板的**上下两条电源轨中间是断开的**（左右不通）。
> 如果左边的模块没电，用两根短跳线把左右两段电源轨连起来即可。
> 你的蓝板已经插在面包板上了，`3V3`(标着 3V3) 和 `GND` 在板子下端那两排插针上。

## 4. 建议的接线顺序（一步一步来，别一次全插上）

1. **只接 ST-Link + OLED**，编译下载。屏幕出现开机画面，然后进入第 1 页。
2. 关电，接**光敏**（AO→PA0）和**电位器**（中间脚→PA1）。上电后：
   用手遮光敏，"光照"数字**变小**；转电位器，"电位"数字在 0~4095 之间变化。
3. 接**四个按键**，测试翻页、阈值加减、报警开关。
4. 接**蜂鸣器**，按一下按键听"嘀"声；在设置页把阈值调高（或用手捂住光敏），就会报警。
5. 接 **USB 转 TTL**，电脑串口助手设 115200 8N1，就能看到每 200ms 一行数据：
   `光照,电位器,阈值,报警开关,统计条数`

## 5. 界面与按键速查

| 页面 | 内容 |
| --- | --- |
| 1/4 | 光照值 + 柱状条、阈值 + 柱状条、电位器读数、报警开关（报警时顶部变"报警中"横幅） |
| 2/4 | 亮度曲线（128 点，约 32 秒窗口） |
| 3/4 | 参数设置（K2/K3 加减阈值，长按 K4 恢复默认阈值） |
| 4/4 | 历史统计（本次上电后的条数、平均、最大、最小，K3 长按清空） |

统计每 **10 秒**记一个样本，内存里最多存 256 个（约 43 分钟），存满后自动覆盖最老的；
**掉电就清零**（因为没用 Flash）。

## 6. 想改引脚 / 改参数怎么办

`user/main.c` 最上面的 **"一、硬件配置区"** 里集中了所有引脚和参数：

* `OLED_SCL_PIN` / `OLED_SDA_PIN`：OLED 引脚
* `BUZZER_PIN`：蜂鸣器引脚（改了要同时改 `BUZZER_TIM` / `BUZZER_CH`）
* `KEY1_PIN` ~ `KEY4_PIN`：按键引脚
* `TH_STEP_COARSE` / `TH_DEFAULT` / `TH_MIN` / `TH_MAX`：阈值步进、默认值和范围
* `SAMPLE_PERIOD_MS` / `UI_PERIOD_MS` / `STAT_PERIOD_MS` / `STAT_MAX`：采样和统计参数
* `LIGHT_BIG_IS_BRIGHT` / `ALARM_WHEN_DIM`：光敏方向与报警方向

## 8. 中文界面是怎么做出来的

0.96 寸 OLED 上的汉字是**点阵字库**：每个字用 16×16 个点表示，一个汉字占 32 字节。

| 文件 | 作用 |
| --- | --- |
| `my_app/cn_font_data.h` | 41 个汉字的点阵数据（16×16），由下面的脚本自动生成 |
| `my_app/gen_cn_font.py` | 从 `my_lib/font/ttfttc/黑体.ttf` 生成上面那个字库文件 |
| `my_app/preview_ui.py` | 在电脑上 1:1 预览 4 个页面，并检查有没有缺字 |
| `my_app/ui_preview.png` | 预览图（就是接上屏幕后看到的样子） |

**想加新汉字**（比如加个"温度"）：打开 `gen_cn_font.py`，把新字填进 `CHARS` 字符串，
重新运行，再把 `cn_font_data.h` 复制到 `my_app` 覆盖，然后 `main.c` 里就能直接
`Ui_CnText(x, y, "温度")` 显示它了。

    python my_app/gen_cn_font.py my_app/cn_font_data.h
    python my_app/preview_ui.py  my_app/ui_preview.png

> 字库里没有的字，屏幕上**那一个字的位置会是空白**，其它字不受影响，所以很好排查。
>
> 小提示：`main.c` 和字库都是 **UTF-8** 编码。如果 Keil 编辑里看到中文乱码，
> 打开 Edit → Configuration → Encoding，选 **UTF-8**，再看就正常了（不影响编译结果）。
